# Notes App Back-End Fundamental

## Saran Proyek API yang Mirip

Kalau ingin membuat proyek API yang mirip dengan repositori ini, kamu bisa coba:

1. **Task Management API**  
   Fitur: autentikasi JWT, CRUD task, label, kolaborasi antar user.
2. **Personal Finance API**  
   Fitur: autentikasi, CRUD transaksi, kategori, laporan sederhana.
3. **Bookmark Manager API**  
   Fitur: autentikasi, CRUD bookmark, tag, pencarian, dan berbagi koleksi.
4. **Journal API**  
   Fitur: autentikasi, CRUD jurnal harian, unggah lampiran, dan ekspor data.

Pola arsitektur dan modul pada proyek ini (handler, service, validator, dan plugin Hapi) bisa dipakai ulang untuk proyek-proyek di atas.
